# HR Dashboard

## Project Overview

A professional Human Resources Dashboard created using Microsoft Excel and Google Sheets to organize, clean, and analyze employee data.

This dashboard provides clear insights into workforce information through interactive charts, summaries, and visual reports to support HR decision-making.

## Skills Demonstrated

- Data Entry
- Data Cleaning
- Data Organization
- Excel Functions
- Pivot Tables
- Pivot Charts
- Data Visualization
- Dashboard Design
- Report Formatting
- Attention to Detail

## Features

- Employee Summary Report
- Department Analysis
- Gender Distribution Analysis
- Hiring Trends
- Performance Overview
- Employee Data Insights
- Interactive Charts and Graphs

## Tools Used

- Microsoft Excel
- Google Sheets
- Pivot Tables
- Charts & Graphs

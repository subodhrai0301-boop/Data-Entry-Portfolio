# Sales Dashboard

## Project Overview
A professional sales dashboard created in Microsoft Excel / Google Sheets to analyze sales performance.

## Skills Demonstrated
- Data Cleaning
- Data Entry
- Pivot Tables
- Charts & Graphs
- Dashboard Design
- Excel Functions
- Google Sheets

## Features
- Total Sales KPI
- Average Sales
- Orders Summary
- Sales by City
- Sales by Category
- Sales by Product
- Sales by Salesperson

## Tools Used
- Microsoft Excel
- Google Sheets

# Inventory Tracker

## Project Overview

A professional inventory management tracker created using Microsoft Excel and Google Sheets to organize, monitor, and analyze product inventory data.

This project helps track stock levels, product information, and inventory movements through a structured spreadsheet system designed for accurate data management.

# Inventory Tracker

## Project Overview
An inventory management tracker created in Microsoft Excel / Google Sheets to monitor stock levels and product information.

## Skills Demonstrated
- Data Entry
- Inventory Management
- Data Organization
- Excel Functions
- Conditional Formatting

## Features
- Product Records
- Stock Levels
- Low Stock Alerts
- Category Tracking
- Inventory Summary

## Tools Used
- Microsoft Excel
- Google Sheets

# HR Dashboard

## Project Overview
A human resources dashboard built in Microsoft Excel / Google Sheets to organize and analyze employee data.

## Skills Demonstrated
- Data Entry
- Data Cleaning
- Pivot Tables
- Charts & Graphs
- Dashboard Design
- Excel Functions

## Features
- Employee Summary
- Department Analysis
- Gender Distribution
- Hiring Trends
- Performance Overview

## Tools Used
- Microsoft Excel
- Google Sheets

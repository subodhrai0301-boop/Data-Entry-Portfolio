# Expense Tracker

## Project Overview
A personal and business expense tracker created in Microsoft Excel / Google Sheets to organize and analyze financial records.

## Skills Demonstrated
- Data Entry
- Financial Record Keeping
- Excel Functions
- Data Analysis
- Data Organization

## Features
- Income & Expense Records
- Monthly Summary
- Expense Categories
- Budget Tracking
- Charts & Reports

## Tools Used
- Microsoft Excel
- Google Sheets
